## Способы публикации (Требование 7: «Сайт должен быть опубликован»)

### Вариант 1: GitHub Pages (Бесплатно, 1 минута)
1. Создайте репозиторий на GitHub (например, `fonesubshop`).
2. Загрузите файлы `index.html`, папки `css` и `js`.
3. Перейдите в **Settings -> Pages** репозитория.
4. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`, нажмите **Save**.
5. Через 30 секунд ваш сайт будет доступен по ссылке `https://<ваш_ник>.github.io/fonesubshop/`.

### Вариант 2: Vercel / Netlify (Мгновенно drag-and-drop)
1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop) или [vercel.com](https://vercel.com).
2. Перетащите папку `d:\FoneSubShop` прямо в окно браузера.
3. Сайт моментально опубликуется и выдаст вам публичный URL с бесплатным SSL-сертификатом.

### Вариант 3: Локальный запуск для проверки
В терминале PowerShell в папке проекта:
```powershell
python -m http.server 8000
```
Затем откройте в браузере `http://localhost:8000`.
